# 式量計算

GitHub Pagesで公開できる、HTML/CSS/JavaScript製の式量計算ゲームです。

## 公開方法

1. `index.html`、`style.css`、`script.js` をGitHubリポジトリ直下にアップロードします。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存します。

## 現在の収録状況

- Level 1：全5問。A問題から2問、B問題から2問、C問題から1問を毎回ランダムに抽選します。
- 各カテゴリ内で同じ問題は重複しません。
- Level 2〜4：問題データ未登録のため選択不可です。今後のデータ追加用に枠だけ用意しています。
- 式量は登録された原子量から自動計算し、整数に四捨五入します。
- Level 1の原子量一覧は、Level 1で出題候補に含まれる元素を表示します。ゲーム画面の一覧は縦スクロールできます。

## 問題候補の編集

`script.js` の `LEVEL1_POOLS` にある `A`、`B`、`C` の配列へ、`['化学式', '物質名']` の形式で追加します。各カテゴリから抽選する数は `GAME_DATA[1].categoryCounts` で変更できます。

化学式から式量を自動計算するため、元素の原子量は `COMMON_ATOMIC_MASSES` に登録してください。

## スコア仕様

レベルを `x`、その問題の誤答回数を `y`、その問題にかかった時間を秒単位で `z` として、正解時に次の点数を加算します。

`max(10x, 230(x²+x) - 100xy - 5xz)`

最終ランクは、全問題の理論値合計 `問題数 × 230(x²+x)` に対する得点率で判定します。

- 70%以上：S
- 55%以上：A
- 45%以上：B
- 30%以上：C
- 15%以上：D
- 15%未満：E

ハイスコアはブラウザの `localStorage` に保存されます。同じ端末・同じブラウザで利用する場合に保持されます。

## イオン表記について

入力文中の `HCO^-` は炭酸水素イオン `HCO3^-`、`HSO4^2-` は硫酸水素イオン `HSO4^-` と解釈しています。硫酸水素銅(II)など、一般的な物質として扱いにくい候補は除外しています。

## 今回の更新
- 回答は小数第1位まで入力（例：18.0）。小数点キーを0の隣に配置。
- 入力が `整数.小数1桁` の形式になるまでGOボタンは無効。

- パスした問題の経過時間・ミス数は、次に正解した問題の採点に繰り越して反映。
- リザルトにパス回数を表示。
- 正解・不正解時に約0.3秒のアニメーションを表示。
- Level 1の指定されたSr・Rb・Cu・NH4の塩（塩化物、酸化物、水酸化物、炭酸塩、硫酸塩、炭酸水素塩）をBからCへ移動。
