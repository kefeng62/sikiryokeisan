# 式量計算ゲーム

GitHub Pagesで公開できる、HTML/CSS/JavaScript製の式量計算ゲームです。

## 公開方法

1. `index.html`、`style.css`、`script.js` をGitHubリポジトリ直下にアップロードします。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存します。

## 収録レベル

- **Level 1：全5問**。A問題2問、B問題2問、C問題1問。
- **Level 2：全5問**。A問題2問、B問題2問、C問題1問。
- Level 3〜4は準備中です。
- 各カテゴリ内で同じ化合物は重複せず、毎回ランダムに抽選されます。
- 式量は化学式から原子量を用いて自動計算し、小数第1位に丸めます。

## Level 2の問題候補

- **A問題**：指定された金属イオン・アンモニウムイオンと、シュウ酸イオン、プロピオン酸イオン、塩素酸イオン、臭素酸イオンから作る塩。加えて、指定された炭化水素。
- **B問題**：プロピオンアルデヒド、ブチルアルデヒド、指定された陽イオンとギ酸イオン・プロピオン酸イオン・酪酸イオン・シュウ酸イオンから作る化合物、および個別指定化合物。
- **C問題**：指定された陽イオンとマロン酸イオン・クエン酸イオン・亜リン酸イオン・ヨウ素酸イオンから作る化合物、過塩素酸とその塩、および個別指定化合物。

陽イオンと陰イオンの組み合わせは、電荷が中性になる最簡整数比で組成式を自動生成します。H⁺は対応する酸として登録しています。組み合わせによっては、実在性・安定性が一般的でない化合物も、指定されたイオンの組み合わせに従って候補に含めています。

## パス

- 2回以上誤答するとパスボタンが表示されます（1プレイにつき最大3回）。
- パスすると、現在の問題が同じカテゴリの未出題の化合物に差し替わります。
- パスした問題の経過時間と誤答回数は、次に正解した問題の採点に繰り越されます。

## スコア

レベルを `x`、その問題の誤答回数（繰越分を含む）を `y`、その問題にかかった時間（秒、繰越分を含む）を `z` とすると、正解時の加点は次の通りです。

`max(10x, round(720(x²+x) - 200xy - 30xz))`

最終ランクは、全問題の理論値合計 `問題数 × 720(x²+x)` に対する得点で判定します。

- 70%以上：S
- 55%以上：A
- 45%以上：B
- 30%以上：C
- 15%以上：D
- 15%未満：E

ハイスコアとプレイヤーランク・XPはブラウザの `localStorage` に保存されます。同じ端末・同じブラウザで利用する場合に保持されます。

## 原子量

Level 2で使用する元素（Cd、Sn、Pb、Ba、Cr、V、Mnなど）を原子量一覧に追加しています。ゲーム中の原子量欄には、そのレベルで使用する原子量が表示されます。
\n- 原子量・式量の小数は0.5だけを残し、それ以外は四捨五入して整数にします。\n
