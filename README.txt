式量計算ゲーム：図鑑機能追加版

導入方法
1. ZIP内の script.js を、現在サイトで使用している script.js と差し替えてください。
2. index.html と既存の style.css、effects.css などは変更不要です。
3. ブラウザを再読み込みしてください。

機能
- ホーム画面に「図鑑」ボタンを追加
- Level 1～3の全出題候補を図鑑に収録
- 問題画面に表示された化学種を「発見済み」として端末のlocalStorageに保存
- 未発見の化学種は「？？？」で表示
- 発見済みの化学種は名称、化学式、ゲーム内計算による式量、実際の分子式・組成式を表示
- Level別／全体の表示切り替えと発見数を表示

補足
イオン結晶や鉱物など、独立した分子を作らない物質については「分子式」ではなく「組成式」が実際の化学式に相当します。そのため図鑑では「実際の分子式・組成式」と表記しています。
発見記録はこのブラウザ・端末のlocalStorageに保存されます。
